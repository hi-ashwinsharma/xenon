# @xenon-kit/cli

```bash
npx @xenon-kit/cli init
```

Run inside an existing React project (Vite or Next.js App Router). It installs `@xenon-kit/web`, wires `styles.css` and `XenonProvider` into the app entry when it can, and writes `AGENTS.md` (plus a `CLAUDE.md` import) so AI agents follow Xenon's design rules.

Other commands: `xenon docs` prints the docs, agent index and registry URLs.
